# Play Publisher — керування Google Play Console

Панель на Next.js для Google Play Developer API: релізи, закрите тестування, сторінка магазину, графіка, підписки, локалізація та відгуки.

## Запуск

```bash
npm install
npm run dev
```

Відкрийте `http://localhost:3000` і використайте сторінку «Підключення» для налаштування.

## Конфігурація

- JSON сервісного акаунта: `credentials/service-account.json`.
- Пароль панелі: `.env.local` → `ADMIN_PASSWORD`.
- Переклади OpenAI: `.env.local` → `OPENAI_API_KEY` та `OPENAI_MODEL`.

Для serverless-хостингу можна використати `GOOGLE_SERVICE_ACCOUNT_JSON`. Дані застосунків і тестувальників зберігаються у `data/store.json`, тому рекомендований локальний запуск або VPS.

## Основні розділи

Огляд застосунків, підключення, релізи, закрите тестування, сторінка магазину, графіка, підписки, локалізація та групи тестувальників.

## Обмеження API

Створення застосунків і обов’язкові анкети виконуються у Play Console. Email-списки тестувальників експортуються у CSV, а відгуки API доступні лише за останні сім днів.
