# Play Publisher — керування Google Play Console

Панель на Next.js для Google Play Developer API: релізи, закрите тестування, сторінка магазину, графіка, підписки, локалізація та відгуки.

## Запуск

```bash
npm install
npm run dev
```

Відкрийте `http://localhost:3000` і використайте сторінку «Підключення» для налаштування.

## Конфігурація

Усі користувацькі налаштування доступні на сторінці **«Підключення»** (`/setup`):

- Завантажте JSON-ключ сервісного акаунта Google Cloud.
- Увімкніть Google Play Android Developer API та надайте email сервісного акаунта доступ у Play Console.
- За потреби введіть OpenAI API-ключ і виберіть модель перекладу.

Реєстрація не потрібна. Ключі, застосунки, приховані треки та групи тестувальників зберігаються лише в `localStorage` поточного браузера, окремо за email сервісного акаунта Google. Очищення даних сайту видаляє їх. Використовуйте власний пристрій: скрипти цього сайту мають доступ до локального сховища.

Браузер передає потрібні ключі серверу сайту через HTTPS для виконання Google/OpenAI-запитів. Сервер не записує ключі чи дані панелі у файли або базу даних. API-клієнти ізольовані на рівні запитів. Серверні змінні з ключами та `credentials/service-account.json` більше не використовуються. Старий `data/store.json` автоматично не імпортується.

Для публічного розгортання на Vercel чи іншому Next.js-хостингу потрібен HTTPS. Залиште `ADMIN_PASSWORD` порожнім для публічного доступу; цей необов’язковий загальний пароль можна залишити для приватного розгортання. База даних і серверні змінні з користувацькими ключами не потрібні.

На Vercel Hobby upload-функція має ліміт 300 секунд. Ліміти хостингу на розмір AAB/APK та зображень залишаються чинними.

## Основні розділи

Огляд застосунків, підключення, релізи, закрите тестування, сторінка магазину, графіка, підписки, локалізація та групи тестувальників.

## Обмеження API

Створення застосунків і обов’язкові анкети виконуються у Play Console. Email-списки тестувальників експортуються у CSV, а відгуки API доступні лише за останні сім днів.
